# Entrega do Módulo B — UX/UI

## Fonte oficial

O arquivo editável e a fonte oficial desta entrega estão no Figma:

- [Vida+Fácil — Módulo B: UX/UI](https://www.figma.com/design/Gt2sX3sydfR12zF6HALCAS)

## Escopo entregue

- `01 Wireframes Mobile`: wireframes mobile dos fluxos B01–B11;
- `02 Foundations`: tokens de cor, tipografia, espaçamento, bordas e acessibilidade;
- `03 Components`: biblioteca de componentes e variantes reutilizáveis;
- `04 Prototype Mobile`: fluxos mobile B01–B11;
- `05 Responsive`: adaptações para 360 px, 768 px e 1440 px;
- `06 Evidence`: cobertura dos requisitos, fluxos, responsividade e acessibilidade.

## Anexo à especificação

- [Justificativas de Design](Justificativas_de_Design.md): decisões de design relacionadas às personas, aos requisitos, à acessibilidade e aos fluxos do MVP.

## Observações

O protótipo utiliza dados fictícios e não possui integração com backend nesta etapa.

O Figma permanece como fonte editável da entrega. Este diretório mantém o registo da entrega no repositório e facilita sua rastreabilidade.
